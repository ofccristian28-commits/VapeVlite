# VapeVlite

Minecraft 1.8.9 Forge client.

## Combat modules

- AutoClicker — VapeVlite profile, 15-20 CPS randomized.
- AutoClicker (CrewX) — independent recreation of the CrewX AutoClicker settings/behavior observed in the uploaded reference.
- Aim Assist — independent recreation of the CrewX-style target selection and rotation settings.
- Backtrack — independent recreation of the CrewX-style historical-position/timing settings.
- Jump Reset
- Reach
- No Jump Delay
- No Hit Delay
- FastPlace
- AutoTool

The CrewX-related modules are reimplemented independently from observed behavior/configuration; proprietary bytecode is not copied.
