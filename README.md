# VapeVlite - Forge 1.8.9

Updated modules:
- Reach: decimal 0.1 steps, Min Reach 3.2 / Max Reach 3.3 defaults, optional randomization.
- AutoClicker: Min CPS 15 / Max CPS 20 defaults, optional randomization.
- Jump Reset: jumps automatically after taking a hit when on ground, with configurable delay.
- Backtrack: Min Delay 200 / Max Delay 400 defaults, optional randomization, Show Position, Lag Based, and Only While Attacking options.
- Aim Assist: stronger smoothing and sticky target lock for better tracking.

Configuration is saved to `config/vapevlite.json`.


Added modules: No Jump Delay, No Hit Delay, FastPlace (1-5 ticks), and Auto Tool (0-200 ms).
